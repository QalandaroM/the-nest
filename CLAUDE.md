# THE NEST — инструкция для Claude Code

## Кто мы
Двое начинающих разработчиков делают свой первый хоррор для Роблокса.
Отвечай **на русском**, просто и по шагам (по этапам). Объясняй, что делает код, а не только пиши его.

## Об игре
Мультиплеерный хоррор на 4–8 игроков в тёмном доме.

**Правила:**
1. Один случайный игрок — **монстр**, остальные — **выжившие**.
2. Убили — конец. Воскрешения нет.
3. Монстр берёт тело (E), несёт на плече (медленнее, бить нельзя, бросить — G) и прячет в любой тайник (E) — тело становится **коконом**. Не спрятал — кокона и второго монстра не будет.
4. Чем меньше ударов понадобилось монстру, тем быстрее вылупится кокон:
   1 удар = 30 сек, каждый следующий удар +15 сек (`Config.COCOON_BASE_TIME`, `Config.COCOON_PER_HIT`).
5. Выжившие ищут кокон **без подсказок**. Рвут его, держа E: +1–3% за 0.75 сек. Разорвали — второго монстра нет.
6. Не успели — из кокона вылезает второй монстр, им управляет убитый игрок.
7. Времени у раунда нет. Выжившие побеждают, если соберут **талисман** (оберег Марты) и убьют им монстра
   (`Config.TALISMAN_HITS_TO_KILL` ожогов). Талисман — из 3 частей, у каждой своя загадка:
   цепочка — сейф с кодом из 4 записок, камень — ящик с электрозамком (нужен ток от щитка),
   оправа — свечи у могил в порядке с рисунка Лили. Части кладут на алтарь. Каждый раунд сейф, ящик, алтарь, записки, рисунок Лили и ключ лежат в новых местах, код сейфа и порядок свечей новые.
   Монстры побеждают, если убьют всех раньше.
8. У каждого выжившего фонарик. Если посветить включённым фонариком **прямо на монстра** (ближе `Config.FREEZE_RANGE`), монстр **замирает**: не ходит и не бьёт. Не дольше `FREEZE_MAX_TIME` сек подряд, потом `FREEZE_IMMUNE_TIME` сек свет на него не действует.
9. **Раны реалистичные**: важно, куда и с какого расстояния попали когти. Издалека царапина, вплотную глубокая рана (кровотечение −1 HP раз в 5–10 сек). Рука может оторваться, удар в голову может ослепить или убить, раны на ногах замедляют. HP сами не восстанавливаются.
10. **Бинты**: 3 в открытых комнатах и по 1–2 в закрытых локациях. Бинт лечит царапину (+15 HP), а на глубокой ране только останавливает кровь.

## Технологии
- Язык: **Luau** (файлы `.luau`)
- Синхронизация со Studio: **Rojo** (версия в `rokit.toml`)
- Контроль версий: Git + GitHub

## Структура
```
src/server/   → ServerScriptService.Server      (*.server.luau — серверные скрипты)
src/client/   → StarterPlayer.StarterPlayerScripts.Client  (*.client.luau)
src/shared/   → ReplicatedStorage.Shared        (модули, Config.luau)
tools/        → ServerStorage.Tools             (инструменты для Studio, в игре не запускаются)
docs/         → не синхронизируется (сюжет, описание карты)
```
- `src/shared/Config.luau` — все числа игры. Новые настройки добавляй **туда**, не хардкодь цифры.
- `src/server/RoundManager.server.luau` — цикл раундов, выбор монстра и второй монстр: кокон вылупился → убитый встаёт на его месте с ролью Monster.
- `src/client/HUD.client.luau` — статус раунда, роль, батарея фонарика, ключ, состояние щитка.
- `src/shared/Sounds.luau` — ID всех звуков (Pro Sound Effects из Creator Store). `BatWings`, `BatScreech`, `MusicTrack`, `MusicAmbience` проверены в Studio (грузятся).
- `src/shared/MonsterModel.luau` — облик монстра (олений череп, рога, рёбра, когти), `TalismanModel.luau` — модель талисмана.
- Сервер: `Cocoons` (тело убитого, перенос, тайники, кокон, разрыв, вылупление → событие `ServerStorage.CocoonHatched`), `MonsterAttack` (когти монстра, попадание по частям тела), `Wounds` (модуль: раны, кровотечение, хромота, слепота, оторванные руки, перевязка), `Bandages` (бинты на карте и инструмент «Бинт»), `Doors` (двери по E), `BasementKey` (ключ и запертая дверь в подвал), `PowerPanel` (уличный щиток и свет), `Flashlight` (батарея и зарядка), `FloorCreaks` (скрип пола), `Darkness` (ночь), `LightFreeze` (свет фонарика замораживает монстра, атрибуты `Frozen`, `FreezeImmuneUntil`), `QuestPlacer` (модуль: ставит сейф, ящик и алтарь к случайной стене в случайной комнате каждый раунд), `MonsterVoice` (рычание и дыхание монстра, слышно в радиусе `Config.MONSTER_VOICE_DISTANCE`), `Talisman` (квесты, алтарь, талисман, урон монстру), `Notes` (чтение записок по E), `MonsterSkin` (надевает облик монстра), `MonsterAnims` (модуль: анимации монстра из Blender по ID из `Config.MONSTER_ANIMS` — бег, переноска тела, удары; скример с рёвом, когда заметил выжившего, вылупился из кокона или замер от фонарика). Двери с атрибутом `Bats` выпускают летучих мышей (`Doors`).
- Клиент: `CocoonView` (что видит убитый: тело, вид изнутри кокона), `Combat` (клик когтями, G — положить тело, эффекты ран на экране), `Prompts` (показывает подсказки E только нужной роли), `Ambience` (фоновые звуки), `Music` (тихая музыка раунда, стингер, когда монстр ближе `Config.MONSTER_STINGER_DISTANCE`), `Bats` (скример с мышами), `Critters` (пауки ползают), `RoomName` (название комнаты), `QuestUI` (записка, код сейфа), `ThirdPersonLight` (светлее от 3-го лица, `Config.THIRD_PERSON_BRIGHT`).
- `tools/MapBuilder/` — строит карту «Дом Хейлов» в Studio: `require(game.ServerStorage.Tools.MapBuilder:Clone()).build()` в Command Bar. Модели Toolbox — в `Assets.luau`, из них вырезаются все скрипты. `Quest.luau` — сейф, ящик, свечи, алтарь. Декали кладутся только туда, где лучи нашли ровную стену (`Kit.surfaceClear`).
- `tools/Preview.luau` — посмотреть карту ночью в режиме редактирования.
- `blender/monster.py` — строит 3D-модель монстра в Blender по частям R15 (`blender --background --factory-startup --python blender/monster.py -- export`). Пишет `blender/out/monster.fbx` (не в Git) и `src/shared/MonsterMeshData.luau` (где меш сидит на части тела). Импортированные меши `M_Head`, `M_UpperTorso`… лежат в `ServerStorage.MonsterMeshes`; без них `MonsterModel` надевает старый облик из деталей. Там же риг R15 (`monster_rig.fbx`) и анимации `monster_anim_run/carry/attack/attack2/scream.fbx` — их импортируют в Animation Editor, публикуют и вписывают ID в `Config.MONSTER_ANIMS`.
- `tools/T.luau` — команды для проверки: `pick()` точки бинтов, `meet()` монстр за спиной выжившего, `info()` раны всех, `give(n)` бинты, `kill(n)` убить выжившего «за n ударов», `hide()` спрятать тело, `near()` + `tear()` рвать кокон, `cocoons()` состояние, `code()` код сейфа и порядок свечей, `parts()` / `talisman()` выдать части / талисман, `face()` выживший лицом к монстру, `go("Safe")` телепорт к квесту, `monster()` статуя монстра и талисмана.
- Персонажи не возрождаются сами (`Players.CharacterAutoLoads = false` в RoundManager): убитый ждёт конца раунда.
- `docs/STORY.md` — сюжет, комнаты, где тайники, квесты на талисман, ключ.
- Атрибуты: `workspace.RoundActive`, `workspace.Power`, `workspace.PanelProgress`, `workspace.Quest_Chain/Stone/Frame` (Hidden/Found/Placed), `workspace.TalismanState` (None/Ready/Taken), `workspace.MonsterBurns`; у игрока `HasChain/HasStone/HasFrame`, `TalismanReadyAt`; у игрока `HasKey`, `Charging`, `HitsTaken` (для кокона), `WoundsText`, `Bleeding`, `ArmsLost`, `EyesHurt`, `BlindUntil`, `Bandages`; у монстра `ClawReadyAt`, `CarryingBody`; у убитого `CocoonState` (Body/Cocoon/Destroyed/Hatched); у кокона `HatchAt`, `Progress`, `Hits`; у фонарика `Battery`.

**Карта строится скриптом `MapBuilder` один раз в Studio и сохраняется в `.rbxl` (в Git — только скрипт).**
Код должен находить объекты карты по имени и спокойно работать, если их нет (`FindFirstChild` + проверка).

## Договорённости в коде
- Роль игрока хранится в атрибуте `Role` у объекта Player:
  `"Monster"`, `"Survivor"`, `"Dead"`, `"Slain"` (монстр, убитый талисманом) или `nil` (в лобби).
- Вся игровая логика (удары, смерть, кокон, победа) — **только на сервере**. Клиент лишь показывает и отправляет запросы через RemoteEvent. Сервер проверяет всё, что приходит от клиента.
- Объекты карты, на которые опирается код:
  - `Workspace.MonsterSpawn`, `Workspace.SurvivorSpawn` — точки спавна (Part)
  - `Workspace.Hideouts` — папка с точками-тайниками для коконов (Part)
  - `Workspace.Quest` — Safe, Chest, Candle_Thomas/Martha/Lily, Altar, CodeNotes, RitualNote
  - `Workspace.Zones` — невидимые зоны комнат (имя = название комнаты)
  - `Workspace.BandageSpawns` — точки для бинтов (атрибуты `Area`, `Closed`)
- Используй современный Luau: `task.wait`, `task.delay`, `for _, x in list do`, строки с `` `{}` ``.
- Пиши короткие комментарии на русском.
